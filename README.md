# Campus Smart-Parking System

Academic Assignment for Programming in Java (CO1).

## Environment & Tech Stack
- **Language**: Java 21 LTS
- **Build Tool**: Apache Maven
- **Version Control**: Git
- **Testing**: JUnit 5

## Project Structure
```text
Campus Smart-Parking System/
├── pom.xml
├── .gitignore
├── README.md
├── docs/
│   ├── tasks/                  # Task specifications, alternative analysis, pseudocode, complexity analysis
│   └── uml/                    # UML diagrams (Class diagrams, Sequence diagrams, etc.)
└── src/
    ├── main/
    │   ├── java/com/smartparking/
    │   │   ├── app/            # Integrated campus parking application entry point & orchestration
    │   │   ├── model/          # Shared domain models & entities
    │   │   ├── service/        # Business logic & services
    │   │   └── tasks/          # Individual standalone task programs (Task 1 to Task 12)
    │   └── resources/
    └── test/
        ├── java/com/smartparking/
        └── resources/
```
